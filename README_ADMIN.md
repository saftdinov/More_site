# Доработка сайта «Море»

## Запуск
Откройте `index.html` через Live Server. Панель администратора: `admin.html`.

## Доступ к демонстрационной панели
Пароль: `more2026`. Это учебный пароль на стороне браузера, не безопасная авторизация для публикации в интернете. Для production необходим сервер, хеширование пароля и база данных.

## Возможности
- Управление участниками: добавить, редактировать имя, роль, цитату и фото, удалить.
- Клиентская форма отзывов; новые отзывы ожидают модерации.
- Администратор может публиковать, снимать с публикации и удалять отзывы.
- Изменения хранятся в localStorage данного браузера. Фото уменьшаются перед сохранением.
- Исправлены мобильное меню, кнопка «Наверх» и передача выбранной песни из репертуара в пожелания на странице бронирования.

Важно: localStorage не синхронизируется между устройствами и браузерами.
