# Кавер-группа «Море» — обновлённая версия

## Что изменено
- Страница бронирования: выбор начальной и конечной даты календарём, проверка диапазона дат.
- Страница участников: сохранена карусель участников с центральной и боковыми карточками.
- Страница «О нас»: горизонтальная лента видеороликов; можно добавить локальные видео для просмотра в текущем браузере (они не загружаются на сервер и не сохраняются между устройствами).
- Портфолио: динамические карточки выступлений; отзывы с публикацией только после одобрения; форма отзыва.
- Админ-панель: управление участниками, отзывами и карточками выступлений.
- Репертуар: множественный выбор песен, корзина, очистка и передача выбранных песен в пожелания бронирования.
- Общий футер вынесен в `footer.html`, стили — в `style/footer.css`; цвет фона `#20242B`. Подключение выполняет `js/footer.js`.

## Запуск
Футер подключается через `fetch`, поэтому сайт нужно открывать через локальный веб-сервер, а не двойным щелчком по HTML-файлу. Например, из папки проекта:

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000`.

## Админ-панель
Откройте `admin.html`. Демонстрационный пароль: `more2026`. Данные хранятся в `localStorage` текущего браузера; это учебная клиентская реализация, не серверная система.
